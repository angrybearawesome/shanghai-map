# 사용자 장소(내 장소) 설계 — 클로드 없이 장소 추가

> 2026-08-10 · 대상: `public/index.html` (단일 파일 원칙 유지, 서버 없음)
> 배경: 여행 중에는 클로드를 쓸 수 없다. 친구들도 브라우저만으로 장소를
> 추가·공유할 수 있어야 한다. 리서치·검증·정식 등록(승격)은 여행 후 클로드가 한다.

## 첫 질문 (디자인 가이드 §0 통과)

- 이 기능의 첫 질문: "지금 알게 된 장소를 지도에 바로 남길 수 있나?"
- 답: 푸터 '＋ 장소 추가' → 이름·분류·메모 입력 → 지도를 한 번 눌러 위치 지정 → 저장.
  좌표 리서치가 필요 없다 — **베이스맵 타일이 GCJ-02라서, 지도에서 찍은 좌표가 곧
  고덕 좌표다.**

## 두 계층 구조

| | 정식 장소 (01~NN) | 내 장소 (uXXXX) |
|---|---|---|
| 저장 | `public/index.html`의 카드 (전원 공통) | localStorage `shcafemap.uplaces.v1` (브라우저별) |
| 추가 | 클로드 `/place` (리서치·검증·배포) | UI에서 즉시 |
| 삭제 | 클로드 `/place 삭제` (번호 재정렬 없음) | 카드의 '이 장소 삭제' (본인 자유) |
| 숨기기 | 카드 '숨기기' → `shcafemap.hidden.v1`, 푸터에서 복원 | 필요 없음 (삭제로 충분) |
| 핀 | 그룹색 (파랑/청록/자주) | **회색** + 번호 대신 ✦ |
| 카운트 | 헤더·탭·범례·푸터 숫자에 포함 | **모든 공식 숫자에서 제외**, '내 장소' 섹션에 자체 카운트 |

숫자에서 제외하는 이유: 공식 숫자는 파일(전원 공통) 기준이어야 verify와 사람의
머릿속이 일치한다. 내 장소는 브라우저마다 다르므로 섞으면 "왜 내 지도는 34곳이야?"가 된다.

## 데이터 모델

```js
// shcafemap.uplaces.v1
[{ uid: 'u' + Date.now().toString(36) + 난수,   // 기기 간 충돌 확률 무시 가능
   name, group: 'cafe'|'spot'|'tea', memo: '',
   lat: number|null, lon: number|null }]        // null = 목록만 (nopin)
// shcafemap.hidden.v1  — 숨긴 정식 장소 id 배열 ['03', ...]
```

내 장소는 시작 시(그리고 변경 시) **정식 카드와 같은 `<article class="card uplace">`
DOM으로 물질화**되어 `#uplist`에 들어가고, `spots`/`cards` 배열에 합류한다.
→ 핀·팝업·방문 기록·계획 패널·주변 추천이 전부 공짜로 동작한다 (재사용 원칙).

## 위치 지정 — "지도에서 찍기"

- 폼에서 '지도에서 찍기' → 폼이 잠시 닫히고 픽 모드. **지도를 한 번 탭/클릭**하면
  그 지점의 GCJ-02 좌표가 잡히고 폼이 다시 열린다. 드래그·확대는 픽 모드에서도 그대로.
- 위치를 모르면 '위치 없이 추가' — `unknown/nopin` 장소처럼 목록에만 표시.

## 공유 — 계획 링크에 내 장소 동봉 (v3)

- 계획 스톱이 내 장소(uid)를 참조하면 공유 링크가 **v3 JSON 포맷**으로 전환된다:
  `{v:3, d:[[{t,i|n,g,r}...]], u:[{i,n,g,la,lo,m}]}` → base64url.
  내 장소가 없으면 기존 v2 초압축 유지 (링크 짧게).
- 받는 쪽: 확인 후 **내 장소를 먼저 자동 추가**(중복 판별: 같은 uid, 또는 같은
  이름 + 좌표 60m 이내 → 기존 것 재사용) → 일차 추가. v1·v2 링크는 계속 호환.

## 승격(정식 등록) — UI가 아니라 클로드 워크플로

여행 후 클로드에게: "내 장소 중 ○○를 정식 등록해줘" 또는 계획 공유 링크를 붙여넣기.
클로드는 `/place` 절차(리서치→검증→카드→배포)로 정식 카드를 만든다.
**한계(문서화됨)**: 내 장소 uid로 쌓인 방문 기록은 정식 번호로 자동 이관되지 않는다
— 필요하면 localStorage에서 uid→새 번호로 수동/스크립트 치환.

## 비범위 (v1에서 안 함)

- 승격 요청 버튼, 내 장소 개별 좌표 수정 UI(삭제 후 재추가로 대체),
  숨긴 장소 개별 복원(전체 복원만), 내 장소 단독 공유 링크(계획 동봉으로 충분).

## 검증

verify.mjs: 폼으로 추가(목록만) → 카드 생성 / uplaces 주입 → 회색 핀 /
지도 찍기 픽 모드 e2e / 정식 장소 숨기기·복원 / v3 공유 왕복(내 장소 자동 추가).
공식 카운트 검사는 localStorage가 빈 상태에서 돌므로 영향 없음.
