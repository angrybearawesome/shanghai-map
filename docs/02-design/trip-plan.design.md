# 여행 계획(일차별 동선) 설계

> 2026-08-07 · 대상: `public/index.html` (단일 파일 원칙 유지, API 키 없음)

## 목적

여행의 "계획 → 실제 이동 → 완료 → 후기" 중 **계획** 단계를 담당한다.
출발 전에 일차별로 시간·장소를 나열해 동선을 미리 짜고, 구간마다 거리·소요
시간·교통편을 확인한다. 기존 방문 기록(실제 이동)·일일 루트(완료)의 앞단.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 이동 시간 계산 | **하이브리드** — 좌표 기반 자동 추정 + 수동 입력 우선 |
| UI 배치 | **탭 전환** — 헤더 아래 `지도 | 계획` 뷰 전환 바 |
| 저장 | localStorage `shcafemap.plan.v1` (방문 기록과 같은 패턴) |

## 데이터 모델

```js
{ days: [                    // 1일차, 2일차, …
  { stops: [                 // 하루 안의 순서 있는 스톱 목록
    { time: '11:00',         // HH:MM, 비울 수 있음
      name: '분당',          // 자유 텍스트
      placeId: '15'|null,    // 지도 카드와 연결되면 카드 id
      lat, lon,              // 연결 시 카드 좌표 복사, 아니면 null
      leg: {min, mode}|null  // 이 스톱 → 다음 스톱 구간의 수동 입력값
    } ] } ] }
```

- `leg`는 **출발 스톱에 붙는다**. 스톱을 이동하면 구간 정보도 따라간다.
- 자동 추정값은 저장하지 않고 렌더링 때마다 계산한다 (visits→루트와 동일 철학).

## 구간 자동 추정 (직선거리 × 보정계수, 참고용)

- 거리: 하버사인. GCJ-02 좌표끼리의 차이라 근거리에선 오차 상쇄.
- 도보 4.5km/h ×1.35 (d ≤ 2.5km일 때만 표시)
- 지하철 34km/h ×1.3 + 접근·대기 11분 (1.2 ≤ d ≤ 45km)
- 택시 22km/h(시내) / 50km/h(15km 이상) ×1.4 + 승차 4분 (항상 표시)
- d > 60km → "장거리 — 고속철 확인" 안내
- 수동 입력(leg)이 있으면 항상 추정보다 우선. 비행기·공항버스 구간용.
- 앞뒤 스톱에 시간이 다 있으면 계획 간격 vs 소요 시간을 비교해
  **여유 N분 / N분 부족** 배지를 표시한다.

## UI

- 헤더 아래 `#views` 바: `지도 | 계획`. 계획 모드에서는 그룹 탭·범례·기록 바·
  목록을 숨기고 `#plan`을 보인다. **지도는 항상 유지** (모바일 sticky 상단,
  데스크톱 우측 컬럼) → 계획 동선 미리보기가 바로 보인다.
- 일차 섹션: `N일차 · M곳` + `지도에 동선`(토글) + `삭제` + `＋ 장소 추가`.
- 스톱 행: 순번 배지(지도 연결 시 그룹색·클릭하면 지도 이동) + `time` 입력 +
  장소 텍스트 입력(`datalist` 자동완성 = 지도 23곳) + `주변`·↑·↓·✕.
- 구간 행(스톱 사이): `1.9km · 도보 34분 · 지하철 15분 · 택시 12분` + 여유/부족
  배지 + `수정`(분·교통편 인라인 입력, `자동`으로 복귀).
- 주변 패널: 그 스톱에서 3km 내 등록 장소를 가까운 순 8곳 — `지도` 보기,
  `다음에 추가`로 동선에 삽입 + 고덕 주변 검색 링크.
- `지도에 동선`: 좌표 있는 스톱들을 파란 점선(`#routes path.plan`)으로 연결,
  일일 루트(방문 기록) 선과 공존.
- 계획 전체 `복사` 텍스트 내보내기 (방문 기록 복사와 같은 UX).
